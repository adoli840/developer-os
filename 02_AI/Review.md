# Review

## Purpose

This document defines project review and code review criteria for AI work.

## Project Review Checklist

- Does the project run?
- Is the README sufficient?
- Are configuration and environment variables clear?
- Is there a test or verification method?
- Is the folder structure maintainable?
- Is the database choice appropriate?
- Are there convenience improvements?
- Can efficiency be improved through automation?
- Are there duplicated features or common module candidates?

## Code Review Checklist

- Does the implementation match the goal?
- Does it duplicate existing code?
- Is there a test or verification method?
- Is the structure maintainable?
- Are there obvious performance risks?
- Is documentation update required?
- Is a decision record required?
