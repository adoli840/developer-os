# AI Workspace

## Purpose

This directory contains the AI operating layer for DeveloperOS.

Its purpose is to make GPT, Codex, and future AI coding agents follow stable rules instead of re-deciding the same things repeatedly.

## Core Documents

- `AI_Collaboration.md`: Role split, handoff rules, and token-saving collaboration model for GPT and Codex
- `AI_Workflow_Safety_Policy.md`: Git, snapshot, recovery, and cost-aware AI workflow policy
- `LanguagePolicy.md`: Official documentation language policy for DeveloperOS
- `../00_Master/GovernanceModel.md`: Relationship between global DeveloperOS policy and project-local rules
- `Rules.md`: AI operating rules
- `Prompts.md`: Reusable prompts
- `Memory.md`: Long-term AI memory
- `Review.md`: Code review and project inspection criteria
- `CodingStyle.md`: Coding style guidance
- `Architecture.md`: Architecture decision guidance
