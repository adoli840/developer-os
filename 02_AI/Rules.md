# AI Rules

## Purpose

This document provides concise AI rules for daily work.

## Workspace-First Rule

AI must check DeveloperOS before meaningful project work.

## Inspection-First Rule

During the current phase, active project inspection and foundation stabilization take priority over new development.

## Reuse Rule

Before creating new code, check existing projects, Blueprints, and decisions.

## Documentation Rule

Important changes must be documented.

## Decision Rule

Record difficult-to-reverse choices such as language, database, architecture, deployment, and AI integration.

## Blueprint Rule

Repeated work should be extracted into `03_Blueprints`.

## Snapshot Rule

Create a snapshot before large or risky multi-file work.
