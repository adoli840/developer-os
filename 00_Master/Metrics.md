# Metrics

## Purpose

This document defines lightweight productivity metrics for DeveloperOS.

The goal is not to pressure the developer. The goal is to make progress, documentation quality, testing, and roadmap alignment visible.

## Developer Score

Developer Score is a soft signal, not a judgment.

| Area | Weight | Description |
|---|---:|---|
| Goal Completion | 25 | Completion rate of planned weekly goals |
| Roadmap Alignment | 20 | Work matches current priorities and deadlines |
| Documentation | 15 | README, decisions, and context are kept current |
| Verification | 15 | Tests or manual verification are performed |
| Commit Hygiene | 10 | Git history remains meaningful and readable |
| AI Knowledge Update | 10 | DeveloperOS is updated when important context changes |
| Focus Stability | 5 | Context switching is controlled |

Do not optimize for score at the expense of useful work.
