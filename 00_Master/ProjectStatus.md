# Project Status

## Purpose

This document tracks the current state of each active project.

DeveloperOS uses this document to provide status reviews, priority recommendations, and progress warnings.

## Status Values

| Status | Meaning |
|---|---|
| Active | Currently being worked on |
| Inspection | Under review before new development |
| Maintenance | Stable, occasional updates only |
| Paused | Intentionally stopped |
| Blocked | Cannot proceed without external input or decision |
| Archived | No longer active |

## Staleness Rule

A project should be flagged when it has not been worked on for 14 days and is still marked Active, Inspection, or High priority.

The flag is advisory. It is not a failure signal.
