# AI Project Prompt

Before starting or modifying this project, check the following:

1. Review `DeveloperOS/00_Master` operating principles.
2. Check whether the feature duplicates another existing project.
3. Check reusable Blueprints in `DeveloperOS/03_Blueprints`.
4. Run `make context TASK="<current request>"` when `PROJECT_AREAS.json` exists.
5. Decide whether language, database, Docker, or AI integration choices are needed.
6. Update README and Decisions when appropriate.
7. Record commonization candidates in the DeveloperOS Backlog.
